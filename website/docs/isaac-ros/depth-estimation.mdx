# Depth Estimation with Isaac ROS

## Introduction to Depth Estimation

Depth estimation is a fundamental capability in robotics that enables robots to understand the 3D structure of their environment. Isaac ROS provides optimized packages for depth estimation that leverage NVIDIA's GPU acceleration to achieve real-time performance.

This chapter focuses on stereo-based depth estimation using Isaac ROS packages, which computes depth information from stereo camera pairs. We'll cover the theory behind stereo depth estimation, how Isaac ROS implements these algorithms, and practical implementation approaches.

## Theory of Stereo Depth Estimation

### Stereo Vision Basics

Stereo depth estimation uses two cameras to compute depth information based on the principle of triangulation. When the same point in space is viewed from two different positions (the two cameras), the point appears at slightly different positions in the two images. This difference is called the "disparity."

The relationship between disparity and depth is:
```
depth = (baseline * focal_length) / disparity
```
Where:
- Baseline: Distance between the two cameras
- Focal_length: Camera focal length in pixels
- Disparity: Difference in pixel positions between left and right images

### Challenges in Stereo Depth Estimation

1. **Textureless Regions**: Areas with little texture have no distinctive features to match
2. **Occlusions**: Objects visible to one camera but not the other
3. **Repetitive Patterns**: Similar textures can cause incorrect matches
4. **Lighting Conditions**: Changing lighting can affect feature matching
5. **Real-time Processing**: Balancing accuracy with computational performance

### Using Isaac ROS Stereo Dense Reconstruction

```python
# Example implementation of stereo dense reconstruction
from geometry_msgs.msg import TransformStamped
from sensor_msgs.msg import Image, CameraInfo
from stereo_msgs.msg import DisparityImage
from visualization_msgs.msg import Marker, MarkerArray
from std_msgs.msg import Header
import rclpy
from rclpy.node import Node
import numpy as np
import open3d as o3d

class StereoDepthEstimator(Node):
    def __init__(self):
        super().__init__('stereo_depth_estimator')
        
        # Create subscribers
        self.left_sub = self.create_subscription(
            Image, '/camera/left/image_rect_color', self.left_image_callback, 10)
        self.right_sub = self.create_subscription(
            Image, '/camera/right/image_rect_color', self.right_image_callback, 10)
        self.disparity_sub = self.create_subscription(
            DisparityImage, '/disparity_output', self.disparity_callback, 10)
        
        # Create publisher for depth images
        self.depth_pub = self.create_publisher(Image, '/depth_output', 10)
        self.pointcloud_pub = self.create_publisher(PointCloud2, '/pointcloud_output', 10)
        
        # Camera parameters (these would typically come from camera_info topics)
        self.baseline = 0.1  # 10 cm between cameras
        self.focal_length = 320.0  # In pixels
        self.cx, self.cy = 320.0, 240.0  # Principal point
        
        # Store latest images
        self.latest_left_image = None
        self.latest_right_image = None
        
    def left_image_callback(self, msg):
        # Store latest left image
        self.latest_left_image = msg
        
    def right_image_callback(self, msg):
        # Store latest right image
        self.latest_right_image = msg
        
    def disparity_callback(self, msg):
        """Process disparity image to generate depth image"""
        # Convert disparity message to depth
        if msg.image.encoding != '32FC1':
            self.get_logger().error(f"Expected 32FC1 encoding, got {msg.image.encoding}")
            return
            
        # Get disparity data
        disparity_array = np.frombuffer(msg.image.data, dtype=np.float32)
        disparity_image = disparity_array.reshape((msg.image.height, msg.image.width))
        
        # Compute depth from disparity
        # depth = (baseline * focal_length) / disparity
        # Add small epsilon to avoid division by zero
        depth_image = np.divide(
            self.baseline * self.focal_length,
            np.maximum(disparity_image, 0.1),
            out=np.full_like(disparity_image, 0.0),
            where=disparity_image > 0.1
        )
        
        # Create depth image message
        depth_msg = Image()
        depth_msg.header = msg.image.header
        depth_msg.height = msg.image.height
        depth_msg.width = msg.image.width
        depth_msg.encoding = '32FC1'
        depth_msg.is_bigendian = False
        depth_msg.step = msg.image.width * 4  # 4 bytes per float32
        depth_msg.data = depth_image.astype(np.float32).tobytes()
        
        # Publish depth image
        self.depth_pub.publish(depth_msg)
        
        # Convert to point cloud
        pointcloud_msg = self.depth_to_pointcloud(depth_image, msg.image.header)
        if pointcloud_msg:
            self.pointcloud_pub.publish(pointcloud_msg)
    
    def depth_to_pointcloud(self, depth_image, header):
        """Convert depth image to point cloud"""
        height, width = depth_image.shape
        points = []
        
        # Generate pixel coordinates
        u, v = np.meshgrid(np.arange(width), np.arange(height))
        
        # Convert pixel coordinates to 3D points
        z = depth_image
        x = (u - self.cx) * z / self.focal_length
        y = (v - self.cy) * z / self.focal_length
        
        # Flatten and stack
        points = np.stack([x.flatten(), y.flatten(), z.flatten()], axis=1)
        
        # Filter out invalid points (where depth is 0)
        valid_points = points[points[:, 2] > 0]
        
        # Create PointCloud2 message (simplified)
        from sensor_msgs.msg import PointCloud2, PointField
        import std_msgs.msg
        
        # Create PointCloud2 message
        pc2_msg = PointCloud2()
        pc2_msg.header = header
        pc2_msg.height = 1
        pc2_msg.width = len(valid_points)
        pc2_msg.fields = [
            PointField(name='x', offset=0, datatype=PointField.FLOAT32, count=1),
            PointField(name='y', offset=4, datatype=PointField.FLOAT32, count=1),
            PointField(name='z', offset=8, datatype=PointField.FLOAT32, count=1)
        ]
        pc2_msg.is_bigendian = False
        pc2_msg.point_step = 12  # 3 * 4 bytes for x, y, z as float32
        pc2_msg.row_step = pc2_msg.point_step * pc2_msg.width
        pc2_msg.is_dense = True
        pc2_msg.data = valid_points.astype(np.float32).tobytes()
        
        return pc2_msg
```

## Optimizing Stereo Depth Estimation

### Performance Optimization Techniques

1. **Resolution Management**:
   - Process at lower resolution for speed
   - Use higher resolution for detail-sensitive tasks

```python
def adjust_processing_resolution(self, original_width, original_height, target_fps):
    """
    Adjust resolution based on target FPS
    """
    # Rule of thumb: stereo processing cost is roughly proportional to width * height
    base_resolution = 640 * 480
    base_fps = 15  # FPS at base resolution
    
    # Calculate target resolution based on desired FPS
    adjustment_factor = base_fps / target_fps
    area_factor = np.sqrt(adjustment_factor)
    
    new_width = int(original_width / area_factor)
    new_height = int(original_height / area_factor)
    
    # Round to multiples of 32 for GPU optimization
    new_width = (new_width // 32) * 32
    new_height = (new_height // 32) * 32
    
    return new_width, new_height
```

2. **Parameter Tuning**:

```python
def tune_stereo_parameters_for_scene(self, scene_complexity):
```

### Quality Optimization Techniques

1. **Multi-scale Processing**:
   - Compute depth at multiple scales
   - Combine results for better quality

2. **Temporal Filtering**:
   - Use temporal consistency to improve depth maps
   - Reduce noise in dynamic scenes

```python
class TemporalDepthFilter:
    def __init__(self, alpha=0.7):
        self.alpha = alpha  # Weight for current frame
        self.prev_depth = None
        
    def filter_depth(self, current_depth):
        """
        Apply temporal filtering to reduce noise
        """
        if self.prev_depth is None:
            self.prev_depth = current_depth.copy()
            return current_depth
            
        # Apply exponential moving average
        filtered_depth = self.alpha * current_depth + (1 - self.alpha) * self.prev_depth
        self.prev_depth = filtered_depth.copy()
        
        return filtered_depth
```

```python
def validate_depth_estimation_in_sim(robot, expected_depth_values):
    """
    Validate depth estimation accuracy in Isaac Sim simulation
    """
    # Get ground truth depth from Isaac Sim
    ground_truth_depth = robot.get_ground_truth_depth()
    
    # Get estimated depth from Isaac ROS pipeline
    estimated_depth = robot.get_estimated_depth()
    
    # Compute accuracy metrics
    mse = np.mean((ground_truth_depth - estimated_depth) ** 2)
    rmse = np.sqrt(mse)
    
    # Compute percentage of pixels within threshold
    threshold = 0.1  # 10cm threshold
    within_threshold = np.abs(ground_truth_depth - estimated_depth) < threshold
    accuracy = np.mean(within_threshold) * 100
    
    return {
        'rmse': rmse,
        'accuracy_within_threshold': accuracy,
        'mean_error': np.mean(ground_truth_depth - estimated_depth)
    }
```

## Troubleshooting Depth Estimation

### Common Issues and Solutions

**Issue: Depth estimation performs poorly in low-texture areas**
- **Cause**: Stereo matching algorithms rely on texture to find corresponding points
- **Solution**: 
  - Improve lighting to increase contrast
  - Add artificial texture to surfaces if possible
  - Use active illumination techniques
  - Combine with other depth sensors (LiDAR)

**Issue: Incorrect depth at object boundaries**
- **Cause**: Disparity computation struggles with edges
- **Solution**:
  - Apply edge-preserving smoothing
  - Use sub-pixel refinement
  - Apply boundary masks

**Issue: Noise in depth output**
- **Cause**: Matching errors or sensor noise
- **Solution**:
  - Apply median filtering
  - Use temporal consistency
  - Apply confidence-based filtering

### Quality Assessment

Evaluate depth estimation quality using metrics:

```python
def assess_depth_quality(estimated_depth, ground_truth_depth):
    """
    Assess depth estimation quality using multiple metrics
    """
    # Mask out invalid pixels (where ground truth is 0)
    valid_mask = ground_truth_depth > 0
    valid_estimated = estimated_depth[valid_mask]
    valid_ground_truth = ground_truth_depth[valid_mask]
    
    if len(valid_ground_truth) == 0:
        return {}
    
    # Calculate metrics
    mse = np.mean((valid_estimated - valid_ground_truth) ** 2)
    rmse = np.sqrt(mse)
    mae = np.mean(np.abs(valid_estimated - valid_ground_truth))
    
    # Percentage of pixels within various thresholds
    thresholds = [0.05, 0.1, 0.2, 0.5, 1.0]  # meters
    accuracy_metrics = {}
    for t in thresholds:
        within_threshold = np.abs(valid_estimated - valid_ground_truth) < t
        accuracy_metrics[f'accuracy_within_{t}m'] = np.mean(within_threshold) * 100
    
    return {
        'rmse': rmse,
        'mae': mae,
        'accuracy_metrics': accuracy_metrics
    }
```
