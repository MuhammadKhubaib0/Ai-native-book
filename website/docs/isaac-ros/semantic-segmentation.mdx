# Semantic Segmentation with Isaac ROS

## Introduction to Semantic Segmentation

Semantic segmentation is a computer vision task that assigns a semantic label to each pixel in an image, enabling robots to understand scene composition at a detailed level. Unlike object detection which identifies objects with bounding boxes, semantic segmentation provides pixel-level understanding of the environment, allowing robots to identify drivable surfaces, obstacles, different object types, and other scene elements with spatial precision.

Isaac ROS provides optimized semantic segmentation packages that leverage NVIDIA's GPU acceleration to achieve real-time performance for robotics applications, making it practical for mobile robots, autonomous systems, and manipulation tasks.

## Understanding Semantic Segmentation in Robotics

### Key Applications

Semantic segmentation in robotics enables:

1. **Navigation**: Identifying drivable terrain vs obstacles
2. **Manipulation**: Understanding object shapes and boundaries
3. **Scene Understanding**: Recognizing different environment types
4. **Safety**: Identifying hazardous areas or objects

### Segmentation vs. Detection

While object detection provides bounding boxes around objects, semantic segmentation provides:

- Pixel-level object boundaries
- Understanding of object shapes and topology
- Ability to distinguish between connected objects
- Detailed spatial relationships

# semantic_segmentation_node.py
from sensor_msgs.msg import Image
from vision_msgs.msg import SegmentedObjectArray, SegmentedObject
from std_msgs.msg import Header
from cv_bridge import CvBridge
import rclpy
from rclpy.node import Node
import numpy as np
import cv2
from typing import Dict, List, Tuple

class IsaacROSSemanticSegmenter(Node):
    def __init__(self):
        super().__init__('isaac_ros_semantic_segmenter')
        
        # Create subscribers
        self.image_sub = self.create_subscription(
            Image, '/camera/image_raw', self.image_callback, 10)
        
        # Create publishers
        self.segmentation_pub = self.create_publisher(
            Image, '/segmentation_mask', 10)
        self.segmented_objects_pub = self.create_publisher(
            SegmentedObjectArray, '/segmented_objects', 10)
        self.visualization_pub = self.create_publisher(
            Image, '/segmentation_visualization', 10)
        
        # Initialize components
        self.bridge = CvBridge()
        self.class_colormap = self.create_coco_colormap()
        self.class_names = self.get_coco_class_names()
        
    def get_coco_class_names(self) -> List[str]:
        """
        Get COCO dataset class names
        """
        return [
            'person', 'bicycle', 'car', 'motorcycle', 'airplane', 'bus', 'train', 
            'truck', 'boat', 'traffic light', 'fire hydrant', 'stop sign', 
            'parking meter', 'bench', 'bird', 'cat', 'dog', 'horse', 'sheep', 
            'cow', 'elephant', 'bear', 'zebra', 'giraffe', 'backpack', 'umbrella', 
            'handbag', 'tie', 'suitcase', 'frisbee', 'skis', 'snowboard', 
            'sports ball', 'kite', 'baseball bat', 'baseball glove', 'skateboard', 
            'surfboard', 'tennis racket', 'bottle', 'wine glass', 'cup', 'fork', 
            'knife', 'spoon', 'bowl', 'banana', 'apple', 'sandwich', 'orange', 
            'broccoli', 'carrot', 'hot dog', 'pizza', 'donut', 'cake', 'chair', 
            'couch', 'potted plant', 'bed', 'dining table', 'toilet', 'tv', 
            'laptop', 'mouse', 'remote', 'keyboard', 'cell phone', 'microwave', 
            'oven', 'toaster', 'sink', 'refrigerator', 'book', 'clock', 'vase', 
            'scissors', 'teddy bear', 'hair drier', 'toothbrush'
        ]
        
    def create_coco_colormap(self) -> Dict[int, Tuple[int, int, int]]:
        """
        Create a colormap for COCO classes
        """
        # Generate distinct colors for each class
        np.random.seed(42)  # For reproducible colors
        colormap = {}
        
        for i in range(len(self.get_coco_class_names())):
            # Generate random RGB values
            color = tuple(np.random.randint(0, 255, size=3).tolist())
            colormap[i] = color
            
        # Ensure background (class 0) is black
        colormap[0] = (0, 0, 0)
        
        return colormap
    
    def image_callback(self, msg):
        """
        Process incoming image and perform semantic segmentation
        """
        try:
            # Convert ROS Image to OpenCV format
            cv_image = self.bridge.imgmsg_to_cv2(msg, desired_encoding='rgb8')
            
            # Perform semantic segmentation
            segmentation_mask = self.run_semantic_segmentation(cv_image)
            
            # Publish raw segmentation mask
            mask_msg = self.bridge.cv2_to_imgmsg(segmentation_mask.astype(np.uint8), encoding='mono8')
            mask_msg.header = msg.header
            self.segmentation_pub.publish(mask_msg)
            
            # Generate segmented objects
            segmented_objects_msg = self.create_segmented_objects_msg(
                segmentation_mask, msg.header
            )
            self.segmented_objects_pub.publish(segmented_objects_msg)
            
            # Create visualization
            vis_image = self.visualize_segmentation(cv_image, segmentation_mask)
            vis_msg = self.bridge.cv2_to_imgmsg(vis_image, encoding='rgb8')
            vis_msg.header = msg.header
            self.visualization_pub.publish(vis_msg)
            
        except Exception as e:
            self.get_logger().error(f'Error in semantic segmentation: {str(e)}')
    
    def run_semantic_segmentation(self, image):
        """
        Run semantic segmentation on the input image
        This is a simplified representation - actual implementation would use Isaac ROS nodes
        """
        # In a real implementation, this would interface with Isaac ROS segmentation nodes
        # For demonstration, we'll simulate segmentation results
        height, width = image.shape[:2]
        
        # Create a mock segmentation mask
        segmentation_mask = np.zeros((height, width), dtype=np.uint8)
        
        # Simulate some segmentation results
        # In reality, this would come from a neural network
        # Create some mock regions for different classes
        
        # Person in the center
        center_x, center_y = width // 2, height // 2
        cv2.circle(segmentation_mask, (center_x, center_y), 100, 1, thickness=-1)
        
        # Chair in the top right
        cv2.rectangle(segmentation_mask, (width - 150, 50), (width - 50, 150), 56, thickness=-1)
        
        # Plant in the bottom left
        cv2.rectangle(segmentation_mask, (50, height - 100), (150, height - 50), 58, thickness=-1)
        
        return segmentation_mask
    
    def create_segmented_objects_msg(self, segmentation_mask, header):
        """
        Create SegmentedObjectArray message from segmentation mask
        """
        segmented_objects_msg = SegmentedObjectArray()
        segmented_objects_msg.header = header
        
        # Find unique classes in the segmentation mask (excluding background)
        unique_classes = np.unique(segmentation_mask)
        unique_classes = unique_classes[unique_classes != 0]  # Exclude background
        
        for class_id in unique_classes:
            if class_id >= len(self.class_names):
                continue  # Skip if class ID is out of range
                
            # Create a mask for this class
            class_mask = (segmentation_mask == class_id).astype(np.uint8) * 255
            
            # Find contours to get bounding boxes
            contours, _ = cv2.findContours(class_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
            
            for contour in contours:
                # Create SegmentedObject
                obj = SegmentedObject()
                
                # Calculate bounding box
                x, y, w, h = cv2.boundingRect(contour)
                obj.bounding_box.center.x = x + w / 2
                obj.bounding_box.center.y = y + h / 2
                obj.bounding_box.size_x = w
                obj.bounding_box.size_y = h
                
                # Set object ID (classification)
                obj.object_name = self.class_names[class_id] if class_id < len(self.class_names) else f"unknown_{class_id}"
                
                # Add to array
                segmented_objects_msg.segmented_objects.append(obj)
        
        return segmented_objects_msg
    
    def visualize_segmentation(self, image, segmentation_mask):
        """
        Create color visualization of segmentation results
        """
        # Create color mask
        color_mask = np.zeros((segmentation_mask.shape[0], segmentation_mask.shape[1], 3), dtype=np.uint8)
        
        # Apply colors based on the colormap
        for class_id, color in self.class_colormap.items():
            color_mask[segmentation_mask == class_id] = color
        
        # Blend the original image with the color mask
        alpha = 0.5  # Transparency factor
        blended = cv2.addWeighted(image, 1 - alpha, color_mask, alpha, 0)
        
        return blended

### Panoptic Segmentation

Combining instance segmentation with semantic segmentation:

```python
# Panoptic segmentation combines instance and semantic segmentation
# This provides both class labels and instance identification
class PanopticSegmenter:
    def __init__(self):
        self.semantic_segmenter = IsaacROSSemanticSegmenter()
        self.instance_segmenter = InstanceSegmenter()  # Would be a separate component
        
    def panoptic_segmentation(self, image):
        """
        Combine semantic and instance segmentation results
        """
        # Get semantic segmentation
        semantic_mask = self.semantic_segmenter.run_semantic_segmentation(image)
        
        # Get instance segmentation (for thing classes)
        instance_results = self.instance_segmenter.run_instance_segmentation(image)
        
        # Combine results
        panoptic_result = self.combine_semantic_instance(
            semantic_mask, instance_results
        )
        
        return panoptic_result
    
    def combine_semantic_instance(self, semantic_mask, instance_results):
        """
        Combine semantic and instance segmentation
        """
        # For "stuff" classes (background), use semantic segmentation
        # For "thing" classes (objects), use instance segmentation
        
        # Example mapping
        stuff_classes = {0, 1, 2, 3, 4, 5}  # Examples: sky, road, terrain, vegetation
        thing_classes = {6, 7, 8, 9, 10}    # Examples: person, car, bicycle
        
        # Create panoptic mask
        panoptic_mask = semantic_mask.copy()
        
        # For thing classes, use instance IDs instead of class IDs
        for i, instance in enumerate(instance_results):
            # Get instance mask
            inst_mask = instance['mask']
            class_id = instance['class_id']
            
            if class_id in thing_classes:
                # Use instance ID in panoptic result
                # Format: [semantic_id * 1000 + instance_id]
                instance_id = i + 1  # Start from 1 to avoid background conflict
                panoptic_mask[inst_mask] = class_id * 1000 + instance_id
        
        return panoptic_mask
```

        self.path_planner = path_planner
        self.driveable_classes = {0, 1, 2, 3}  # Examples: road, sidewalk, terrain
        self.obstacle_classes = {5, 6, 7}      # Examples: person, car, bicycle
        
    def update_costmap_from_segmentation(self, segmentation_mask, robot_pose):
        """
        Update navigation costmap based on segmentation results
        """
        height, width = segmentation_mask.shape
        map_resolution = 0.05  # 5 cm per cell
        
        # Convert segmentation mask to costmap
        for y in range(height):
            for x in range(width):
                class_id = segmentation_mask[y, x]
                
                # Convert image coordinates to map coordinates
                map_x = robot_pose[0] + (x - width/2) * map_resolution
                map_y = robot_pose[1] + (y - height/2) * map_resolution
                
                if class_id in self.obstacle_classes:
                    # Mark as obstacle in costmap
                    self.path_planner.update_costmap_cell(
                        map_x, map_y, cost=254  # High cost
                    )
                elif class_id in self.driveable_classes:
                    # Mark as free space with low cost
                    self.path_planner.update_costmap_cell(
                        map_x, map_y, cost=0    # Low cost
                    )
                else:
                    # Unknown class, assign medium cost
                    self.path_planner.update_costmap_cell(
                        map_x, map_y, cost=100  # Medium cost
                    )
    
    def identify_traversable_path(self, segmentation_mask):
        """
        Identify potentially traversable regions from segmentation
        """
        traversable_mask = np.zeros_like(segmentation_mask, dtype=np.uint8)
        
        # Mark driveable surfaces
        for class_id in self.driveable_classes:
            traversable_mask[segmentation_mask == class_id] = 255

## Quality Assessment and Evaluation

### Segmentation Quality Metrics

```python
def calculate_segmentation_metrics(true_mask, pred_mask, num_classes):
    """
    Calculate semantic segmentation metrics
    """
    # Calculate Intersection over Union (IoU) for each class
    ious = []
    
    for class_id in range(num_classes):
        # Create binary masks for this class
        true_class = (true_mask == class_id).astype(np.uint8)
        pred_class = (pred_mask == class_id).astype(np.uint8)
        
        # Calculate intersection and union
        intersection = np.logical_and(true_class, pred_class).sum()
        union = np.logical_or(true_class, pred_class).sum()
        
        if union == 0:
            iou = 1.0 if intersection == 0 else 0.0  # Perfect match or no pixels
        else:
            iou = intersection / union
            
        ious.append(iou)
    
    # Calculate mean IoU (mIoU)
    mean_iou = np.mean(ious)
    
    # Calculate pixel accuracy
    pixel_accuracy = np.mean(true_mask == pred_mask)
    
    # Calculate per-class accuracy
    class_accuracies = []
    for class_id in range(num_classes):
        class_mask = (true_mask == class_id)
        if np.sum(class_mask) > 0:
            class_acc = np.mean(pred_mask[class_mask] == class_id)
            class_accuracies.append(class_acc)
        else:
            class_accuracies.append(1.0)  # If no pixels of class, accuracy is 1
    
    mean_class_accuracy = np.mean(class_accuracies)
    
    return {
        'iou_per_class': ious,
        'mean_iou': mean_iou,
        'pixel_accuracy': pixel_accuracy,
        'class_accuracy_per_class': class_accuracies,
        'mean_class_accuracy': mean_class_accuracy
    }
```

## Troubleshooting Segmentation

### Common Issues and Solutions

**Issue: Blurry segment boundaries**
- **Cause**: Low-resolution model or insufficient context
- **Solution**:
  - Use higher resolution inputs
  - Implement boundary refinement networks
  - Apply post-processing with CRF (Conditional Random Fields)

**Issue: Inconsistent segmentation across frames**
- **Cause**: Model instability or temporal inconsistencies
- **Solution**:
  - Apply temporal smoothing
  - Use optical flow for temporal consistency
  - Implement post-processing filters

**Issue: Poor performance on small objects**
- **Cause**: Limited receptive field or model scale
- **Solution**:
  - Use multi-scale inputs
  - Implement attention mechanisms
  - Use pyramid pooling structures

            'avg_mIoU': sum(self.segmentation_quality) / len(self.segmentation_quality) if self.segmentation_quality else 0,
            'min_inference_time_ms': min(self.inference_times),
            'max_inference_time_ms': max(self.inference_times),
            'std_inference_time_ms': np.std(self.inference_times)
        }
