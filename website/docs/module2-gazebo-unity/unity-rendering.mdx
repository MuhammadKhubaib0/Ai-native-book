# Unity for High-Fidelity Rendering

## Overview

In this chapter, we'll explore how to use Unity for creating high-fidelity rendering environments for robotics applications. We'll cover ML-Agents integration, creating realistic humanoid environments, lighting and materials, and how to connect these Unity environments with ROS 2 for robotics simulation.

Unity is a powerful game engine that provides high-quality rendering capabilities that are perfect for simulating realistic visual appearances, lighting conditions, and complex environments. When combined with ML-Agents, it becomes a powerful platform for training AI agents in photorealistic environments.

## Unity ML-Agents Integration

Unity ML-Agents (Machine Learning Agents) is a toolkit that enables games and simulations to serve as environments for training intelligent agents using deep reinforcement learning and imitation learning. This is particularly useful for robotics applications where agents need to learn complex behaviors.

### Installing ML-Agents

First, you'll need to install the ML-Agents toolkit in your Unity project:

1. In Unity, go to Window > Package Manager
2. Click the "+" button in the top left
3. Select "Add package from git URL..."
4. Enter "com.unity.ml-agents" and click Add

Alternatively, you can add it via the manifest file (`Packages/manifest.json`):

```json
{
  "scopedRegistries": [],
  "dependencies": {
    "com.unity.ml-agents": "2.4.0-exp.1",
    // ... other dependencies
  }
}
```

### Basic ML-Agents Setup

Here's a simple example of setting up an ML-Agents environment in Unity:

```csharp
using Unity.MLAgents;
using Unity.MLAgents.Sensors;
using Unity.MLAgents.Actuators;
using UnityEngine;

public class RobotAgent : Agent
{
    [Header("Robot Specific")]
    public Transform targetTransform;  // The target the agent should reach
    public float movementSpeed = 5f;

    public override void OnEpisodeBegin()
    {
        // Reset agent and target positions at the start of each episode
        transform.position = new Vector3(Random.Range(-5f, 5f), 0f, Random.Range(-5f, 5f));
        targetTransform.position = new Vector3(Random.Range(-5f, 5f), 0f, Random.Range(-5f, 5f));
    }

    public override void CollectObservations(VectorSensor sensor)
    {
        // Observe the relative position of the target
        sensor.AddObservation(targetTransform.position - transform.position);
        // Observe the agent's own velocity (if applicable)
        // sensor.AddObservation(velocity);
    }

    public override void OnActionReceived(ActionBuffers actions)
    {
        // Process actions (for example, 3 continuous actions for movement)
        float forward = actions.ContinuousActions[0];
        float right = actions.ContinuousActions[1];
        float up = actions.ContinuousActions[2];

        // Move the agent
        transform.position += new Vector3(right, up, forward) * movementSpeed * Time.deltaTime;

        // Calculate distance to target
        float distanceToTarget = Vector3.Distance(transform.position, targetTransform.position);

        // Give reward based on distance to target
        if (distanceToTarget < 1.0f)
        {
            SetReward(1.0f);
            EndEpisode();
        }
        else
        {
            SetReward(-0.01f * distanceToTarget);  // Small negative reward for time spent
        }
    }

    public override void Heuristic(in ActionBuffers actionsOut)
    {
        // Manual control for testing
        var continuousActionsOut = actionsOut.ContinuousActions;
        continuousActionsOut[0] = Input.GetAxis("Vertical");  // Forward/back
        continuousActionsOut[1] = Input.GetAxis("Horizontal"); // Right/left
        continuousActionsOut[2] = Input.GetKey(KeyCode.E) ? 1f : -1f; // Up/down
    }
}
```

## Creating Realistic Humanoid Environments in Unity

Unity excels at creating photorealistic environments. Here's how to build a realistic humanoid environment:

### 1. Environment Setup

First, create a basic environment:

- Create a ground plane using a Cube scaled to appropriate dimensions (e.g., 20x1x20)
- Add obstacles and structures using Unity's primitive objects or imported 3D models
- Set up lighting to simulate realistic conditions

### 2. Lighting Configuration

Realistic lighting is crucial for high-fidelity rendering:

```csharp
using UnityEngine;

public class EnvironmentLighting : MonoBehaviour
{
    [Header("Lighting Settings")]
    public Light mainLight;
    public float dayNightCycleSpeed = 0.5f;

    private float currentTime = 0.5f; // Start at noon

    void Update()
    {
        // Simulate day/night cycle
        currentTime += dayNightCycleSpeed * Time.deltaTime * 0.01f;
        if (currentTime > 1.0f) currentTime = 0.0f;

        // Position the sun based on time
        float sunAngle = currentTime * 360f - 90f; // Start at sunrise
        float sunHeight = Mathf.Sin(currentTime * Mathf.PI) * 10f + 1f;
        
        mainLight.transform.rotation = Quaternion.Euler(sunAngle, 0, 0);
        mainLight.intensity = Mathf.Clamp01(Mathf.Sin(currentTime * Mathf.PI));
    }
}
```

### 3. Materials and Textures

For high-fidelity rendering, quality materials are essential:

1. Use physically-based rendering (PBR) materials
2. Import high-resolution textures with appropriate specular, normal, and occlusion maps
3. Configure material properties to match real-world properties

### 4. Post-Processing Effects

Add post-processing effects to enhance realism:

- Ambient Occlusion
- Bloom
- Color Grading
- Depth of Field
- Motion Blur

## Connecting Unity with ROS 2

To connect Unity environments with ROS 2, we can use rosbridge_suite, which allows communication between ROS nodes and external systems using WebSocket connections.

### Installing and Setting Up Rosbridge

1. Install rosbridge_suite:
```bash
sudo apt install ros-humble-rosbridge-suite
```

2. Launch the rosbridge server:
```bash
ros2 launch rosbridge_server rosbridge_websocket_launch.xml
```

### Unity ROS Bridge Integration

To integrate Unity with ROS 2, we need to establish communication. Here's a basic example using WebSocket connection:

```csharp
using System;
using System.Collections;
using UnityEngine;
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Sensor;
using RosMessageTypes.Geometry;

public class UnityROSConnector : MonoBehaviour
{
    ROSConnection ros;
    float publishMessageFrequency = 0.1f;
    int robotCount = 0;

    public GameObject robotPrefab;  // Prefab of your robot
    public Transform[] spawnPoints; // Array of spawn positions

    // Start is called before the first frame update
    void Start()
    {
        // Get ROS connection static instance
        ros = ROSConnection.GetOrCreateInstance();
        ros.RegisterPublisher<NavSatFixMsg>("/unity/gps_data");
        
        // Start the coroutine to publish messages
        StartCoroutine(PublishMessage());
    }

    IEnumerator PublishMessage()
    {
        // Wait for the specified number of seconds
        yield return new WaitForSeconds(publishMessageFrequency);
        
        // Publish a message
        NavSatFixMsg gps_msg = new NavSatFixMsg();
        gps_msg.latitude = transform.position.x;
        gps_msg.longitude = transform.position.z;
        gps_msg.altitude = transform.position.y;

        // Publish the message
        ros.Publish("/unity/gps_data", gps_msg);
        
        // Start this Coroutine again
        StartCoroutine(PublishMessage());
    }

    public void SpawnRobot()
    {
        // Spawn a robot at a random spawn point
        Transform spawnPoint = spawnPoints[robotCount % spawnPoints.Length];
        Instantiate(robotPrefab, spawnPoint.position, spawnPoint.rotation);
        robotCount++;
    }
}
```

### Image and Sensor Data Streaming

To stream image data from Unity to ROS 2:

```csharp
using UnityEngine;
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Sensor;
using System;

public class CameraSensor : MonoBehaviour
{
    ROSConnection ros;
    public Camera camera;
    [Range(0.1f, 10.0f)]
    public float publishRate = 1.0f; // Hz

    // CompressedImage publisher
    private Texture2D texture;
    private RenderTexture renderTexture;
    private byte[] imageBytes;

    void Start()
    {
        ros = ROSConnection.GetOrCreateInstance();
        
        // Create render texture for the camera
        renderTexture = new RenderTexture(640, 480, 24);
        camera.targetTexture = renderTexture;
        
        texture = new Texture2D(640, 480, TextureFormat.RGB24, false);
        
        // Start the coroutine to publish images
        StartCoroutine(PublishImages());
    }

    IEnumerator PublishImages()
    {
        while (true)
        {
            yield return new WaitForSeconds(1.0f / publishRate);
            
            // Capture the camera image
            RenderTexture.active = renderTexture;
            texture.ReadPixels(new Rect(0, 0, renderTexture.width, renderTexture.height), 0, 0);
            texture.Apply();
            
            // Convert to bytes
            imageBytes = texture.EncodeToJPG();
            
            // Create and publish the image message
            ImageMsg imgMsg = new ImageMsg
            {
                header = new std_msgs.HeaderMsg
                {
                    stamp = new builtin_interfaces.TimeMsg
                    {
                        sec = (int)(Time.timeSinceLevelLoad),
                        nanosec = (uint)((Time.timeSinceLevelLoad % 1) * 1e9)
                    },
                    frame_id = "unity_camera"
                },
                height = (uint)texture.height,
                width = (uint)texture.width,
                encoding = "rgb8",
                is_bigendian = 0,
                step = (uint)(texture.width * 3), // 3 bytes per pixel for RGB
                data = imageBytes
            };
            
            ros.Publish("/unity/camera/image_raw", imgMsg);
        }
    }
}
```

## Best Practices for Unity Robotics Simulation

### 1. Performance Optimization

- Use occlusion culling to avoid rendering hidden objects
- Implement level of detail (LOD) systems for complex models
- Optimize textures (use appropriate compression, resolution)
- Use object pooling for frequently instantiated objects

### 2. Physics Simulation

- Configure Unity's physics settings to match real-world physics
- Use appropriate mass, drag, and angular drag values for objects
- Consider using Fixed Timestep for consistent physics simulation

### 3. Sensor Simulation

- Use Unity's built-in Camera component for RGB cameras
- Implement custom shaders for special sensor effects
- Consider using Unity's raycasting for LiDAR simulation

### 4. Realistic Rendering

- Use High Definition Render Pipeline (HDRP) or Universal Render Pipeline (URP) for advanced rendering
- Implement realistic materials with appropriate physical properties
- Use image-based lighting (IBL) for realistic reflections and lighting
