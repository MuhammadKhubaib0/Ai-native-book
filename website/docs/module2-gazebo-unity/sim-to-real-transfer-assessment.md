   b) Discrepancies between simulation and reality that cause performance differences
   c) Difference in programming languages used

   b) To make policies robust to variations by randomizing simulation parameters

   b) Determining actual system parameters from input-output data

4. Which of the following is NOT a source of the reality gap?

   b) Physical property differences
   c) Control timing differences
   d) Programming language differences

   a) To eliminate the need for simulation entirely
   b) To make real-world robots exactly like simulated ones
   c) To ensure simulation-trained models perform well in the real world
