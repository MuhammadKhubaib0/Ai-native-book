# Sim-to-Real Transfer Techniques

## Overview

In this final chapter of Module 2, we'll explore sim-to-real transfer techniques—methods to bridge the gap between simulation and reality. The "reality gap" refers to the differences between simulated and real environments that can cause policies learned in simulation to perform poorly when transferred to real robots.

Successfully addressing the reality gap is crucial for robotics deployment, as simulation provides a safe, fast, and cost-effective way to develop and test algorithms before real-world implementation. The techniques covered in this chapter will help ensure that your simulation-trained models perform well in the real world.

## Understanding the Reality Gap

The reality gap arises from various sources of discrepancy between simulation and reality:

1. **Visual Differences**: Lighting, textures, colors, and rendering quality
2. **Physical Differences**: Material properties, friction, dynamics, and sensor noise
3. **Control Differences**: Actuator delays, joint positioning errors, and control frequency
4. **Environmental Differences**: Air resistance, dust, uneven surfaces, and temperature

### Key Discrepancies

| Aspect | Simulation | Reality |
|--------|------------|---------|
| Sensor Noise | Perfectly modeled | Complex, variable patterns |
| Dynamics | Simplified physics | Complex interactions |
| Visual Appearance | Consistent textures | Varying lighting, shadows |
| Control Timing | Perfect synchronization | Communication delays |

## Domain Randomization

Domain randomization is one of the most effective techniques for sim-to-real transfer. It involves randomizing simulation parameters during training to make the learned policy robust to variations in the real world.

### Implementation Strategy

The core idea is to vary simulation parameters across a wide range of possible values:

```python
import random
import numpy as np

class DomainRandomizer:
    def __init__(self, env):
        self.env = env
        self.param_ranges = {
            'lighting': (0.1, 1.0),  # Intensity range
            'color': (0.0, 1.0),     # Color variation
            'friction': (0.1, 1.0),  # Friction range
            'mass': (0.5, 2.0),      # Mass multiplier
            'gravity': (8.8, 10.8),  # Gravity range
        }
    
    def randomize_environment(self):
        """Randomize environment parameters for domain randomization"""
        # Randomize lighting
        lighting_intensity = random.uniform(
            self.param_ranges['lighting'][0], 
            self.param_ranges['lighting'][1]
        )
        self.env.set_lighting(lighting_intensity)
        
        # Randomize object colors
        object_color = [random.uniform(0, 1) for _ in range(3)]
        self.env.set_object_color(object_color)
        
        # Randomize friction coefficients
        friction = random.uniform(
            self.param_ranges['friction'][0], 
            self.param_ranges['friction'][1]
        )
        self.env.set_friction(friction)
        
        # Randomize object masses
        mass_multiplier = random.uniform(
            self.param_ranges['mass'][0], 
            self.param_ranges['mass'][1]
        )
        self.env.set_mass(mass_multiplier)
        
        # Randomize gravity
        gravity_val = random.uniform(
            self.param_ranges['gravity'][0], 
            self.param_ranges['gravity'][1]
        )
        self.env.set_gravity([0, 0, -gravity_val])
        
        return f"Environment randomized with lighting={lighting_intensity:.2f}, friction={friction:.2f}"

# Example usage during training
def train_with_domain_randomization():
    # Initialize environment and randomizer
    env = SimulationEnvironment()
    domain_randomizer = DomainRandomizer(env)
    
    for episode in range(10000):  # Training episodes
        # Randomize environment for each episode
        randomization_info = domain_randomizer.randomize_environment()
        print(f"Episode {episode}: {randomization_info}")
        
        # Train your policy in the randomized environment
        train_policy(env)
        
        if episode % 1000 == 0:
            # Test on a consistent real-world-like environment
            test_policy_on_realistic_env(env)
```

For more sophisticated domain randomization, we can randomize textures, material properties, and sensor models:

```python
import cv2
import numpy as np
from PIL import Image

class AdvancedDomainRandomizer:
    def __init__(self, env):
        self.env = env
        # Load various textures for randomization
        self.textures = self.load_textures()
        
    def load_textures(self):
        """Load various textures for domain randomization"""
        # In practice, this would load from a directory of textures
        return [
            # texture1, texture2, ...
        ]
    
    def randomize_visual_domain(self):
        """Randomize visual aspects of the environment"""
        # Randomize background using textures
        if self.textures:
            random_texture = random.choice(self.textures)
            self.env.set_background_texture(random_texture)
        
        # Randomize fog parameters
        fog_enabled = random.choice([True, False])
        if fog_enabled:
            fog_density = random.uniform(0.0, 0.1)
            fog_color = [random.uniform(0.8, 1.0)] * 3
            self.env.set_fog(fog_density, fog_color)
        
        # Randomize camera noise
        noise_params = {
            'gaussian': random.uniform(0.0, 0.05),
            'salt_pepper': random.uniform(0.0, 0.02),
            'poisson': random.uniform(0.0, 0.1)
        }
        self.env.set_camera_noise(noise_params)
    
    def randomize_dynamics(self):
        """Randomize physical dynamics in the simulation"""
        # Randomize joint friction
        joint_friction_range = (0.0, 0.1)
        for joint in self.env.get_joints():
            friction = random.uniform(*joint_friction_range)
            self.env.set_joint_friction(joint, friction)
        
        # Randomize actuator delays
        delay_range = (0.0, 0.1)  # seconds
        for actuator in self.env.get_actuators():
            delay = random.uniform(*delay_range)
            self.env.set_actuator_delay(actuator, delay)
    
    def apply_systematic_randomization(self):
        """Apply systematic domain randomization"""
        # Apply visual randomization
        self.randomize_visual_domain()
        
        # Apply dynamic randomization
        self.randomize_dynamics()
        
        # Apply sensor randomization
        self.randomize_sensor_models()
    
    def randomize_sensor_models(self):
        """Randomize sensor models to match real-world characteristics"""
        # Randomize LiDAR noise
        lidar_noise = {
            'stddev': random.uniform(0.01, 0.05),
            'bias': random.uniform(-0.01, 0.01)
        }
        self.env.set_lidar_noise(lidar_noise)
        
        # Randomize IMU noise
        imu_noise = {
            'accel_std': random.uniform(0.01, 0.1),
            'gyro_std': random.uniform(0.001, 0.01)
        }
        self.env.set_imu_noise(imu_noise)
```

## System Identification

System identification is a method for determining the actual parameters of a system from input-output data. In sim-to-real transfer, this involves identifying the real robot's dynamics and adjusting the simulation model to better match reality.

### Parameter Estimation

The goal is to find parameters θ that minimize the difference between simulation and real behavior:

```python
import numpy as np
from scipy.optimize import minimize
from scipy import signal

class SystemIdentifier:
    def __init__(self, sim_env, real_robot):
        self.sim_env = sim_env
        self.real_robot = real_robot
        self.parameters = {
            'mass': 1.0,
            'friction': 0.1,
            'inertia': 0.1,
            'actuator_gain': 1.0
        }
    
    def collect_data(self):
        """Collect input-output data from real robot"""
        inputs = []
        outputs = []
        
        # Apply various inputs and record responses
        for input_signal in self.generate_test_signals():
            input_signal = np.array(input_signal)
            self.real_robot.apply_input(input_signal)
            
            # Record output
            output = self.real_robot.get_output()
            
            inputs.append(input_signal)
            outputs.append(output)
        
        return np.array(inputs), np.array(outputs)
    
    def generate_test_signals(self):
        """Generate test signals for system identification"""
        signals = []
        
        # Step response
        step_signal = [0]*10 + [1]*20 + [0]*10
        signals.append(step_signal)
        
        # Impulse response
        impulse_signal = [0]*5 + [2] + [0]*25
        signals.append(impulse_signal)
        
        # Sinusoidal signal
        t = np.arange(0, 30, 0.1)
        sin_signal = np.sin(0.5 * t).tolist()
        signals.append(sin_signal)
        
        return signals
    
    def simulate_with_params(self, params, inputs):
        """Simulate the system with given parameters"""
        # Update simulation parameters
        self.update_simulation_params(params)
        
        sim_outputs = []
        for input_signal in inputs:
            # Apply input to simulation
            self.sim_env.apply_input(input_signal)
            
            # Get simulation output
            output = self.sim_env.get_output()
            sim_outputs.append(output)
        
        return np.array(sim_outputs)
    
    def objective_function(self, param_vector):
        """Objective function to minimize"""
        # Convert parameter vector back to dictionary
        params = self.vector_to_params(param_vector)
        
        # Collect data from real robot
        inputs, real_outputs = self.collect_data()
        
        # Get simulation outputs with current parameters
        sim_outputs = self.simulate_with_params(params, inputs)
        
        # Calculate error between real and simulated outputs
        error = np.mean((real_outputs - sim_outputs)**2)
        
        print(f"Parameter vector: {param_vector}, Error: {error}")
        
        return error
    
    def vector_to_params(self, param_vector):
        """Convert parameter vector to dictionary"""
        if len(param_vector) != 4:
            raise ValueError("Expected 4 parameters")
        
        return {
            'mass': param_vector[0],
            'friction': param_vector[1],
            'inertia': param_vector[2],
            'actuator_gain': param_vector[3]
        }
    
    def params_to_vector(self, params):
        """Convert parameter dictionary to vector"""
        return np.array([
            params['mass'],
            params['friction'],
            params['inertia'],
            params['actuator_gain']
        ])
    
    def update_simulation_params(self, params):
        """Update simulation with new parameters"""
        self.sim_env.set_mass(params['mass'])
        self.sim_env.set_friction(params['friction'])
        self.sim_env.set_inertia(params['inertia'])
        self.sim_env.set_actuator_gain(params['actuator_gain'])
    
    def identify_system(self):
        """Identify system parameters using optimization"""
        # Initial parameter guess
        initial_params = self.params_to_vector(self.parameters)
        
        # Optimize parameters
        result = minimize(
            self.objective_function,
            initial_params,
            method='BFGS',
            options={'disp': True, 'maxiter': 100}
        )
        
        # Update parameters with optimized values
        self.parameters = self.vector_to_params(result.x)
        
        print(f"Optimized parameters: {self.parameters}")
        return self.parameters

# Example usage
def run_system_identification():
    sim_env = SimulationEnvironment()
    real_robot = RealRobotInterface()
    
    identifier = SystemIdentifier(sim_env, real_robot)
    identified_params = identifier.identify_system()
    
    print("System identification complete!")
    print(f"Identified parameters: {identified_params}")
```

## Domain Adaptation Techniques

Domain adaptation techniques help bridge the gap between simulation and reality by adapting models trained on synthetic data to work well on real-world data.

### Cycle Consistent Adversarial Networks (CycleGAN)

CycleGAN can be used to transform synthetic images to look more realistic:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ResidualBlock(nn.Module):
    def __init__(self, in_features):
        super(ResidualBlock, self).__init__()

        conv_block = [nn.ReflectionPad2d(1),
                      nn.Conv2d(in_features, in_features, 3),
                      nn.InstanceNorm2d(in_features),
                      nn.ReLU(inplace=True),
                      nn.ReflectionPad2d(1),
                      nn.Conv2d(in_features, in_features, 3),
                      nn.InstanceNorm2d(in_features)]

        self.conv_block = nn.Sequential(*conv_block)

    def forward(self, x):
        return x + self.conv_block(x)

class Generator(nn.Module):
    def __init__(self, input_nc, output_nc, n_residual_blocks=9):
        super(Generator, self).__init__()

        # Initial convolution block
        model = [nn.ReflectionPad2d(3),
                 nn.Conv2d(input_nc, 64, 7),
                 nn.InstanceNorm2d(64),
                 nn.ReLU(inplace=True)]

        # Downsampling
        in_features = 64
        out_features = in_features*2
        for _ in range(2):
            model += [nn.Conv2d(in_features, out_features, 3, stride=2, padding=1),
                      nn.InstanceNorm2d(out_features),
                      nn.ReLU(inplace=True)]
            in_features = out_features
            out_features = in_features*2

        # Residual blocks
        for _ in range(n_residual_blocks):
            model += [ResidualBlock(in_features)]

        # Upsampling
        out_features = in_features//2
        for _ in range(2):
            model += [nn.ConvTranspose2d(in_features, out_features, 3, stride=2, padding=1, output_padding=1),
                      nn.InstanceNorm2d(out_features),
                      nn.ReLU(inplace=True)]
            in_features = out_features
            out_features = in_features//2

        # Output layer
        model += [nn.ReflectionPad2d(3),
                  nn.Conv2d(64, output_nc, 7),
                  nn.Tanh()]

        self.model = nn.Sequential(*model)

    def forward(self, x):
        return self.model(x)

class Discriminator(nn.Module):
    def __init__(self, input_nc):
        super(Discriminator, self).__init__()

        # A bunch of convolutions one after another
        model = [nn.Conv2d(input_nc, 64, 4, stride=2, padding=1),
                 nn.LeakyReLU(0.2, inplace=True)]

        model += [nn.Conv2d(64, 128, 4, stride=2, padding=1),
                  nn.InstanceNorm2d(128),
                  nn.LeakyReLU(0.2, inplace=True)]

        model += [nn.Conv2d(128, 256, 4, stride=2, padding=1),
                  nn.InstanceNorm2d(256),
                  nn.LeakyReLU(0.2, inplace=True)]

        model += [nn.Conv2d(256, 512, 4, padding=1),
                  nn.InstanceNorm2d(512),
                  nn.LeakyReLU(0.2, inplace=True)]

        # FCN classification layer
        model += [nn.Conv2d(512, 1, 4, padding=1)]

        self.model = nn.Sequential(*model)

    def forward(self, x):
        x = self.model(x)
        # Average pooling and flatten
        return F.avg_pool2d(x, x.size()[2:]).view(x.size()[0], -1)
```

## Simulation-to-Reality Pipeline

Here's a complete pipeline that combines domain randomization and system identification:

```python
class SimToRealPipeline:
    def __init__(self, sim_env, real_robot):
        self.sim_env = sim_env
        self.real_robot = real_robot
        self.domain_randomizer = DomainRandomizer(sim_env)
        self.system_identifier = SystemIdentifier(sim_env, real_robot)
        
    def phase1_train_in_simulation(self, episodes=50000):
        """Phase 1: Train policy in randomized simulation"""
        print("Phase 1: Training in randomized simulation...")
        
        for episode in range(episodes):
            # Randomize environment for each episode
            self.domain_randomizer.apply_systematic_randomization()
            
            # Train policy in randomized environment
            self.train_policy(episode)
            
            if episode % 5000 == 0:
                print(f"Completed {episode} episodes of simulation training")
    
    def phase2_system_identification(self):
        """Phase 2: Identify system parameters"""
        print("Phase 2: System identification...")
        
        # Collect data from real robot
        real_params = self.system_identifier.identify_system()
        
        # Update simulation with identified parameters
        self.sim_env.update_dynamics_model(real_params)
        
        print("System identification complete!")
        
    def phase3_adapt_to_real(self, episodes=1000):
        """Phase 3: Adapt and fine-tune on real robot"""
        print("Phase 3: Adapting to real robot...")
        
        for episode in range(episodes):
            # Train on real robot with minimal randomization
            self.train_on_real_robot(episode)
            
            if episode % 100 == 0:
                print(f"Completed {episode} episodes of real robot training")
    
    def execute_pipeline(self):
        """Execute the complete sim-to-real pipeline"""
        self.phase1_train_in_simulation()
        self.phase2_system_identification()
        self.phase3_adapt_to_real()
        
        print("Sim-to-real pipeline complete!")

# Example usage
def execute_sim_to_real_training():
    sim_env = SimulationEnvironment()
    real_robot = RealRobotInterface()
    
    pipeline = SimToRealPipeline(sim_env, real_robot)
    pipeline.execute_pipeline()
```

## Advanced Transfer Techniques

### 1. Curriculum Learning

Gradually increase the complexity of the simulation to approach reality:

```python
class CurriculumSimToReal:
    def __init__(self, env):
        self.env = env
        self.stages = [
            # Stage 1: Perfect simulation
            {'noise': 0.0, 'texture_randomization': False, 'dynamics_randomization': False},
            # Stage 2: Minor noise
            {'noise': 0.01, 'texture_randomization': False, 'dynamics_randomization': False},
            # Stage 3: Texture randomization
            {'noise': 0.01, 'texture_randomization': True, 'dynamics_randomization': False},
            # Stage 4: Full domain randomization
            {'noise': 0.05, 'texture_randomization': True, 'dynamics_randomization': True},
        ]
        self.current_stage = 0
    
    def advance_stage(self):
        """Advance to the next stage if performance threshold is met"""
        if self.current_stage < len(self.stages) - 1:
            self.current_stage += 1
            self.update_environment()
            print(f"Advanced to stage {self.current_stage + 1}")
    
    def update_environment(self):
        """Update environment with current stage parameters"""
        stage_params = self.stages[self.current_stage]
        
        self.env.set_noise_level(stage_params['noise'])
        self.env.set_texture_randomization(stage_params['texture_randomization'])
        self.env.set_dynamics_randomization(stage_params['dynamics_randomization'])
```

### 2. Simulated Annealing for Domain Randomization

Gradually reduce the range of randomization as training progresses:

```python
class AdaptiveDomainRandomizer:
    def __init__(self, env, initial_variance=1.0, final_variance=0.1, total_episodes=100000):
        self.env = env
        self.initial_variance = initial_variance
        self.final_variance = final_variance
        self.total_episodes = total_episodes
        self.current_episode = 0
    
    def get_current_variance(self):
        """Calculate current variance based on training progress"""
        progress = self.current_episode / self.total_episodes
        # Exponentially decay variance
        current_variance = self.initial_variance * ((self.final_variance / self.initial_variance) ** progress)
        return max(current_variance, self.final_variance)
    
    def randomize_environment(self):
        """Randomize environment with adaptive variance"""
        current_variance = self.get_current_variance()
        
        # Randomize with current variance level
        lighting_variance = current_variance * 0.5
        friction_variance = current_variance * 0.3
        mass_variance = current_variance * 0.2
        
        self.env.set_lighting_randomization(lighting_variance)
        self.env.set_friction_randomization(friction_variance)
        self.env.set_mass_randomization(mass_variance)
        
        self.current_episode += 1
        
        return {
            'variance': current_variance,
            'episode': self.current_episode,
            'lighting': lighting_variance,
            'friction': friction_variance,
            'mass': mass_variance
        }
```

## Evaluation and Validation

To validate sim-to-real transfer effectiveness, we need proper evaluation methods:

```python
def evaluate_sim_to_real_transfer(sim_policy, real_robot, num_trials=50):
    """Evaluate sim-to-real transfer performance"""
    sim_scores = []
    real_scores = []
    
    # Evaluate in simulation
    for trial in range(num_trials):
        score = evaluate_policy_in_simulation(sim_policy)
        sim_scores.append(score)
    
    # Evaluate on real robot
    for trial in range(num_trials):
        score = evaluate_policy_on_real_robot(sim_policy, real_robot)
        real_scores.append(score)
    
    # Calculate statistics
    sim_mean = np.mean(sim_scores)
    sim_std = np.std(sim_scores)
    real_mean = np.mean(real_scores)
    real_std = np.std(real_scores)
    
    # Calculate sim-to-real gap
    gap = sim_mean - real_mean
    
    print(f"Simulation Performance: {sim_mean:.2f} ± {sim_std:.2f}")
    print(f"Real Performance: {real_mean:.2f} ± {real_std:.2f}")
    print(f"Sim-to-Real Gap: {gap:.2f}")
    print(f"Transfer Efficiency: {real_mean/sim_mean*100:.1f}%")
    
    return {
        'sim_mean': sim_mean,
        'sim_std': sim_std,
        'real_mean': real_mean,
        'real_std': real_std,
        'gap': gap,
        'efficiency': real_mean/sim_mean
    }
```
