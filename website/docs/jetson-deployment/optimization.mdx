# Model Optimization for Jetson

## Introduction to Edge AI Optimization

Deploying AI models on edge devices like NVIDIA Jetson platforms requires significant optimization to meet computational, memory, and power constraints. Unlike cloud-based systems with abundant resources, Jetson devices must balance AI performance with real-time robotics requirements, sensor processing, and navigation tasks.

This chapter covers essential optimization techniques specifically for deploying Isaac Sim-trained models to Jetson platforms, focusing on perception and navigation models that form the core of the AI-robot brain.

## Jetson Platform Constraints

### Hardware Limitations

NVIDIA Jetson platforms offer impressive AI performance for edge devices, but have limitations that require model optimization:

- **Computational Power**: Limited compared to data center GPUs
- **Memory**: Constrained RAM and GPU memory
- **Power Consumption**: Battery or limited power source considerations
- **Thermal Management**: Heat dissipation constraints
- **Real-time Requirements**: Robotics applications demand low-latency responses

### Performance Targets

For effective robot perception and navigation on Jetson:

- **Latency**: `<50ms` for perception tasks
- **Throughput**: Sufficient frames per second for robot operation
- **Power Efficiency**: Optimize performance per watt
- **Memory Usage**: Stay within available RAM and GPU memory

## Model Optimization Techniques

### 1. Pruning

Pruning removes unnecessary connections or neurons from neural networks:

- **Weight Pruning**: Remove low-magnitude weights
- **Neuron Pruning**: Remove entire neurons that contribute little
- **Structured Pruning**: Remove structured elements (channels, layers)

```python
import torch
import torch.nn.utils.prune as prune

def prune_model(model, pruning_ratio=0.2):
    """
    Prune a model by removing low-magnitude weights
    """
    for name, module in model.named_modules():
        if isinstance(module, torch.nn.Conv2d) or isinstance(module, torch.nn.Linear):
            prune.l1_unstructured(module, name='weight', amount=pruning_ratio)
            prune.remove(module, 'weight')
    
    return model
```

### 2. Quantization

Quantization reduces the precision of model weights and activations:

- **Post-Training Quantization (PTQ)**: Quantize after training
- **Quantization-Aware Training (QAT)**: Simulate quantization during training

#### TensorRT INT8 Quantization

TensorRT provides optimized INT8 quantization for Jetson:

```python
import tensorrt as trt
import pycuda.driver as cuda

def create_int8_calibrator(data_loader, batch_size):
    """
    Create an INT8 calibrator for TensorRT
    """
    class Int8Calibrator(trt.IInt8Calibrator):
        def __init__(self, data_loader, batch_size):
            trt.IInt8Calibrator.__init__(self)
            self.data_loader = data_loader
            self.batch_size = batch_size
            self.current_index = 0
            
            # Allocate device memory for calibration data
            self.device_input = cuda.mem_alloc(batch_size * trt.volume(self.get_algorithm_io_size(trt.CalibrationAlgoType.ENTROPY_CALIBRATION_2)[0]))
            
        def get_algorithm(self):
            return trt.CalibrationAlgoType.ENTROPY_CALIBRATION_2
            
        def get_batch_size(self):
            return self.batch_size
            
        def get_batch(self, names):
            if self.current_index >= len(self.data_loader):
                return None
            
            batch = self.data_loader[self.current_index]
            self.current_index += 1
            
            # Copy batch to device memory
            cuda.memcpy_htod(self.device_input, batch.numpy())
            return [int(self.device_input)]
            
        def read_calibration_cache(self):
            # Attempt to load calibration cache if it exists
            try:
                with open('calibration_cache.bin', 'rb') as f:
                    return f.read()
            except:
                return None
                
        def write_calibration_cache(self, cache):
            # Write calibration cache to file
            with open('calibration_cache.bin', 'wb') as f:
                f.write(cache)
    
    return Int8Calibrator(data_loader, batch_size)
```

## TensorRT Optimization

### ONNX to TensorRT Conversion

TensorRT provides optimized inference for NVIDIA hardware:

```python
import tensorrt as trt
import onnx
import numpy as np

def build_tensorrt_engine(onnx_model_path, engine_path, max_batch_size=1, 
                         fp16_mode=False, int8_mode=False, calibration_data=None):
    """
    Build a TensorRT engine from an ONNX model
    """
    TRT_LOGGER = trt.Logger(trt.Logger.WARNING)
    builder = trt.Builder(TRT_LOGGER)
    
    # Create network
    network = builder.create_network(1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH))
    config = builder.create_builder_config()
    
    # Parse ONNX model
    parser = trt.OnnxParser(network, TRT_LOGGER)
    with open(onnx_model_path, 'rb') as model:
        parser.parse(model.read())
    
    # Set optimization profiles
    profile = builder.create_optimization_profile()
    # Assuming first input is the image input [N, C, H, W]
    input_shape = network.get_input(0).shape
    min_shape = [1] + input_shape[1:]  # Minimum batch size 1
    opt_shape = [max_batch_size] + input_shape[1:]  # Optimal batch size
    max_shape = [max_batch_size] + input_shape[1:]  # Maximum batch size
    
    profile.set_shape(network.get_input(0).name, min_shape, opt_shape, max_shape)
    config.add_optimization_profile(profile)
    
    # Set precision modes
    if fp16_mode:
        config.set_flag(trt.BuilderFlag.FP16)
    
    if int8_mode:
        config.set_flag(trt.BuilderFlag.INT8)
        config.int8_calibrator = create_int8_calibrator(calibration_data, max_batch_size)
    
    # Build engine
    serialized_engine = builder.build_serialized_network(network, config)
    
    # Save engine
    with open(engine_path, 'wb') as f:
        f.write(serialized_engine)
    
    return serialized_engine
```

## Optimization Workflow

### Step 1: Baseline Assessment

1. Profile original model performance on target Jetson device
2. Measure inference time, memory usage, and power consumption
3. Establish baseline metrics for optimization goals

### Step 2: Sequential Optimization

1. **Model conversion**: Convert from training framework to deployment format
2. **Pruning**: Remove unnecessary parameters
3. **Quantization**: Reduce precision while maintaining accuracy
4. **TensorRT optimization**: Leverage hardware acceleration

### Step 3: Validation

1. Test optimized model accuracy against original
2. Verify real-time performance requirements are met
3. Validate on real robot data in various conditions

## Performance Evaluation

### Metrics for Optimized Models

- **Inference time**: Time per inference on Jetson device
- **Throughput**: Inferences per second
- **Model size**: Memory footprint of the optimized model
- **Accuracy**: Comparison with original model (acceptable loss)
- **Power consumption**: Energy efficiency on the target device

### Benchmarking Tools

NVIDIA provides tools for benchmarking optimized models:

```python
import time
import numpy as np

def benchmark_model(inference_fn, input_data, num_runs=100):
    """
    Benchmark an optimized model's performance
    """
    # Warmup
    for _ in range(10):
        _ = inference_fn(input_data)
    
    # Actual benchmarking
    times = []
    for _ in range(num_runs):
        start_time = time.time()
        _ = inference_fn(input_data)
        end_time = time.time()
        times.append((end_time - start_time) * 1000)  # Convert to milliseconds
    
    avg_time = np.mean(times)
    std_time = np.std(times)
    min_time = np.min(times)
    max_time = np.max(times)
    
    print(f"Average inference time: {avg_time:.2f} ms ± {std_time:.2f}")
    print(f"Min: {min_time:.2f} ms, Max: {max_time:.2f} ms")
    print(f"Throughput: {1000/avg_time:.2f} FPS")
    
    return {
        "avg_time": avg_time,
        "std_time": std_time,
        "min_time": min_time,
        "max_time": max_time,
        "throughput": 1000/avg_time
    }
```

## Best Practices

### 1. Progressive Optimization

- Start with small optimization steps
- Validate accuracy after each optimization step
- Maintain a balance between speed and accuracy

### 2. Hardware-Specific Optimization

- Always profile on the target hardware
- Use TensorRT for NVIDIA devices
- Consider the specific Jetson model's capabilities

### 3. Model Architecture Selection

- Choose architectures suitable for the target hardware
- Consider efficient alternatives like MobileNet, EfficientNet
- Evaluate trade-offs between different model families

### 4. Continuous Evaluation

- Test performance with real robot data
- Monitor for degradation over time
- Plan for model updates and re-optimization

## Troubleshooting Common Issues

### Accuracy Loss After Optimization

- Reduce quantization aggressiveness
- Use Quantization-Aware Training instead of Post-Training Quantization
- Add more calibration data for INT8 quantization

### Performance Not Meeting Requirements

- Review model architecture for more efficient alternatives
- Check for bottlenecks in data preprocessing
- Verify that TensorRT optimization was correctly applied

### Memory Issues

- Reduce batch sizes if using batching
- Apply more aggressive pruning
- Consider model splitting across multiple inference calls
